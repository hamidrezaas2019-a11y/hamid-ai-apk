## 📱 معرفی

**حمید AI** یک دستیار هوش مصنوعی فوق‌العاده با شخصیت‌های دخترانه بی‌نهایت است! این برنامه به شما امکان می‌دهد:

- 💬 **چت هوشمند** با شخصیت‌های مختلف
- 📸 **تولید تصویر** با هوش مصنوعی
- 🎵 **پخش موسیقی** با ویژوالایزر
- 🎬 **پخش ویدیو** از لینک‌های مختلف
- 🤖 **انتخاب مدل‌های AI** مختلف
- 📚 **دسترسی به موضوعات** متنوع
- 🗣️ **قابلیت گفتار** (Voice)

---

## ✨ ویژگی‌های اصلی

| ویژگی | توضیح |
|--------|---------|
| **👥 شخصیت‌ها** | بیش از 100 شخصیت دخترانه با شخصیت‌های متفاوت |
| **💬 چت هوشمند** | پاسخ‌های شخصی‌سازی شده بر اساس شخصیت |
| **📸 تولید تصویر** | ساخت تصویر با پرامپت دلخواه |
| **🎵 پخش موسیقی** | لیست پخش با ویژوالایزر |
| **🎬 پخش ویدیو** | پشتیبانی از لینک‌های مختلف |
| **🤖 مدل‌های AI** | OpenAI، Gemini، Claude، DeepSeek و... |
| **📚 موضوعات** | ورزش، دکوراسیون، باغبانی، سلامت و... |
| **🗣️ گفتار** | پشتیبانی از Web Speech API |
| **📱 PWA** | قابلیت نصب روی موبایل |
