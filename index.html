// ================================================================ // ☁️ Cloudflare Worker - بدون R2 // فقط با D1 Database + API خارجی // ================================================================ // ================================================================ // 📦 تنظیمات اصلی // ================================================================ const CONFIG = { LIMITS: { MAX_SAMPLES: 500, // حداکثر ۵۰۰ نمونه (به دلیل محدودیت D1) MAX_DATA_SIZE: 100 * 1024 // ۱۰۰ کیلوبایت } }; // ================================================================ // 🧠 سرویس اصلی - بدون R2 // ================================================================ class DeepSeekFineTuneService { constructor(env) { this.env = env; this.db = env.DB; // فقط D1 } // ============================================================ // 📝 ۱. ذخیره داده در D1 // ============================================================ async prepareData(data) { const { instructions, outputs } = data; // اعتبارسنجی if (!instructions || !outputs || instructions.length !== outputs.length) { throw new Error('داده‌های ورودی نامعتبر'); } // محدودیت حجم if (instructions.length > CONFIG.LIMITS.MAX_SAMPLES) { throw new Error(`حداکثر ${CONFIG.LIMITS.MAX_SAMPLES} نمونه مجاز است`); } // ساخت داده‌های آماده const preparedData = instructions.map((instruction, i) => ({ instruction: instruction.trim(), output: outputs[i].trim(), prompt: this.buildPrompt(instruction), target: `${outputs[i]}\n<|EOT|>` })); // ایجاد ID یکتا const dataId = `data_${Date.now()}_${Math.random().toString(36).substr(2, 6)}`; // ذخیره در D1 (به صورت JSON) await this.db.prepare( `INSERT INTO training_data (id, data, created_at, status) VALUES (?, ?, CURRENT_TIMESTAMP, 'prepared')` ).bind( dataId, JSON.stringify(preparedData) ).run(); return { success: true, id: dataId, count: preparedData.length, size: JSON.stringify(preparedData).length }; } // ============================================================ // 📝 ۲. ساخت Prompt (مثل کد اصلی) // ============================================================ buildPrompt(instruction) { return `You are an AI programming assistant, utilizing the DeepSeek Coder model, developed by DeepSeek Company, and you only answer questions related to computer science. For politically sensitive questions, security and privacy issues, and other non-computer science questions, you will refuse to answer. ### Instruction: ${instruction.trim()} ### Response: `.trimStart(); } // ============================================================ // 🚀 ۳. شروع Fine-tuning // ============================================================ async startFineTune(dataId, options = {}) { // دریافت داده از D1 const result = await this.db.prepare( 'SELECT data FROM training_data WHERE id = ?' ).bind(dataId).first(); if (!result) { throw new Error('داده‌ها یافت نشد'); } const trainingData = JSON.parse(result.data); // ارسال به سرویس خارجی const jobId = await this.submitToExternalService(trainingData, options); // به‌روزرسانی وضعیت در D1 await this.db.prepare( `UPDATE training_data SET status = 'training', job_id = ?, started_at = CURRENT_TIMESTAMP WHERE id = ?` ).bind(jobId, dataId).run(); return { jobId: jobId, dataId: dataId, status: 'training', estimatedTime: this.estimateTrainingTime(trainingData.length) }; } // ============================================================ // 🔗 ۴. اتصال به Replicate (رایگان‌ترین گزینه) // ============================================================ async submitToExternalService(data, options) { // گزینه ۱: Replicate (پیشنهادی) if (this.env.REPLICATE_API_TOKEN) { return this.runOnReplicate(data, options); } // گزینه ۲: Hugging Face Inference API if (this.env.HUGGINGFACE_TOKEN) { return this.runOnHuggingFace(data, options); } // گزینه ۳: استفاده از WebAssembly (برای داده‌های خیلی کوچک) if (data.length < 50) { return this.runLocallyWasm(data, options); } throw new Error('هیچ سرویس خارجی تنظیم نشده است'); } // ============================================================ // 🎯 ۵. Replicate API // ============================================================ async runOnReplicate(data, options) { // داده‌ها را به فرمت JSON کوچک تبدیل می‌کنیم const smallData = data.map(d => ({ instruction: d.instruction.slice(0, 200), output: d.output.slice(0, 200) })); const response = await fetch('https://api.replicate.com/v1/predictions', { method: 'POST', headers: { 'Authorization': `Token ${this.env.REPLICATE_API_TOKEN}`, 'Content-Type': 'application/json' }, body: JSON.stringify({ version: 'deepseek-ai/deepseek-coder-6.7b-instruct:latest', input: { training_data: smallData, epochs: options.epochs || 1, batch_size: Math.min(options.batchSize || 4, 8), learning_rate: options.learningRate || 2e-5 }, webhook: `${this.env.WORKER_URL}/api/webhook`, webhook_events_filter: ["completed"] }) }); const result = await response.json(); return result.id; } // ============================================================ // 🎯 ۶. Hugging Face Inference API // ============================================================ async runOnHuggingFace(data, options) { // فقط برای داده‌های کوچک const smallData = data.slice(0, 10); const response = await fetch( 'https://api-inference.huggingface.co/models/deepseek-ai/deepseek-coder-6.7b-instruct', { method: 'POST', headers: { 'Authorization': `Bearer ${this.env.HUGGINGFACE_TOKEN}`, 'Content-Type': 'application/json' }, body: JSON.stringify({ inputs: smallData.map(d => d.prompt), parameters: { max_length: 100, temperature: 0.7 } }) } ); // این فقط برای نمونه‌های کوچک کار می‌کند // برای fine-tuning واقعی نیاز به سرویس اختصاصی دارد const result = await response.json(); // ذخیره نتایج const jobId = `hf_${Date.now()}`; await this.db.prepare( `INSERT INTO training_results (job_id, data_id, results, created_at) VALUES (?, ?, ?, CURRENT_TIMESTAMP)` ).bind(jobId, data[0]?.id || 'unknown', JSON.stringify(result)).run(); return jobId; } // ============================================================ // 🎯 ۷. اجرای محلی با WebAssembly (فقط برای نمونه‌های کوچک) // ============================================================ async runLocallyWasm(data, options) { // برای داده‌های بسیار کوچک (کمتر از ۵۰ نمونه) // این یک شبیه‌سازی ساده است const jobId = `local_${Date.now()}`; // پردازش ساده با استفاده از WebAssembly const results = data.map(d => { // شبیه‌سازی پاسخ return { instruction: d.instruction, generated: `Generated response for: ${d.instruction.substring(0, 30)}...` }; }); // ذخیره در D1 await this.db.prepare( `INSERT INTO training_results (job_id, data_id, results, created_at) VALUES (?, ?, ?, CURRENT_TIMESTAMP)` ).bind(jobId, 'local', JSON.stringify(results)).run(); return jobId; } // ============================================================ // 📊 ۸. بررسی وضعیت // ============================================================ async getJobStatus(jobId) { // دریافت از D1 const result = await this.db.prepare( `SELECT * FROM training_data WHERE job_id = ?` ).bind(jobId).first(); if (!result) { throw new Error('Job not found'); } return { jobId: jobId, status: result.status, progress: result.progress || 0, created_at: result.created_at, started_at: result.started_at, completed_at: result.completed_at }; } // ============================================================ // 📥 ۹. دریافت نتایج // ============================================================ async getResults(jobId) { const result = await this.db.prepare( 'SELECT results FROM training_results WHERE job_id = ?' ).bind(jobId).first(); if (!result) { throw new Error('Result not found'); } return JSON.parse(result.results); } // ============================================================ // ⏱️ ۱۰. تخمین زمان // ============================================================ estimateTrainingTime(dataSize) { const baseTime = 60; // ۱ دقیقه const timePerSample = 2; // ۲ ثانیه برای هر نمونه const totalSeconds = baseTime + (dataSize * timePerSample); return { seconds: totalSeconds, minutes: Math.round(totalSeconds / 60), readable: totalSeconds < 60 ? `${totalSeconds} ثانیه` : `${Math.round(totalSeconds / 60)} دقیقه` }; } // ============================================================ // 🔄 ۱۱. Webhook برای دریافت نتایج // ============================================================ async handleWebhook(data) { const { id, status, output } = data; // به‌روزرسانی وضعیت در D1 await this.db.prepare( `UPDATE training_data SET status = ?, completed_at = CURRENT_TIMESTAMP WHERE job_id = ?` ).bind(status === 'succeeded' ? 'completed' : 'failed', id).run(); // ذخیره نتایج if (status === 'succeeded' && output) { await this.db.prepare( `INSERT INTO training_results (job_id, results, created_at) VALUES (?, ?, CURRENT_TIMESTAMP)` ).bind(id, JSON.stringify(output)).run(); } return { success: true }; } } // ================================================================ // 🌐 Cloudflare Worker // ================================================================ export default { async fetch(request, env) { const url = new URL(request.url);
